# 德州扑克 (Texas Hold'em) - game-hold-me

基于 **Vue 3 + Vite** 构建的高端现代德州扑克在线单机/人机对战游戏。

## ✨ 核心特性

1. **纯前端架构 & 后端易拓展**
   - 采用纯前端 Vue 3 Composition API 与响应式状态管理 (`usePokerGame.ts`)。
   - 业务逻辑分层清晰，未来可无缝对接 WebSocket / 后端服务端。

2. **高度自定义对局设置 (开局前/随时配置)**
   - **对手数量设置**：支持 2 ~ 12 人对局（单挑、6人桌、9人桌、满员12人桌），椭圆几何动态自适应排布。
   - **盲注自由拖动**：小盲 20 ~ 200，大盲 40 ~ 400（最小 20/40，最大 200/400）。
   - **4 种独特 AI 人机打法/难度**：
     - **激进哥**：频繁加注、善于诈唬、翻后 C-bet 极高、敢推全下。
     - **非要看**：翻前必跟注看翻牌3张牌才考虑弃牌。
     - **紧紧哥**：极度谨慎，仅玩高强起手牌（AA-77, AK等），入局必有大牌。
     - **大鱼**：纯新手小白，随缘跟注、偶尔盲目反击、容易送筹码。

3. **筹码与钱包系统**
   - 玩家初始筹码 **1,200**。
   - 右上角**筹码钱包**（👛）：单次带入最高 **6,000**（可无限次带入）。
   - **规则风控**：当玩家当前筹码 **> 6,000** 时，禁止带入新筹码，并带有友好提示。

4. **行动倒计时与延时机制**
   - 每位玩家每手行动初始时间 **20 秒**。
   - 带有**环形倒计时进度条**与操作栏**平滑滑动倒计时条**。
   - 每手支持 **1 次延时机会**，点击 `⏱ +10s` 可立即为当前思考增加 10 秒。

5. **全端响应式适配 (手机端 & PC 端)**
   - **手机竖屏模式**：优雅垂直椭圆牌桌，匹配移动端操作习惯。
   - **电脑横屏模式**：宽屏豪华 3D 拟真牌桌，具备木质镶边、LED 轮廓光环及暗色微光质感。
   - 支持红龙酒红 (Burgundy)、尊爵翡翠 (Emerald)、曜石黑金 (Midnight) 3 种桌布主题切换。

6. **完整标准德州扑克规则与高级算法**
   - 7张牌最佳成牌评估算法（皇家同花顺、同花顺、四条、葫芦、同花、顺子、三条、两对、一对、高牌），精细踢脚牌（Kicker）比较。
   - 多人全下边池（Side Pots）准确计算与分配。
   - 胜率实时蒙特卡洛估算。
   - 胜者欢呼烟花粒子特效（Canvas Confetti）。

7. **牌局回顾 & 实时排名**
   - **牌局回顾 (📊)**：记录每局牌的底池、盲注、公共牌、各玩家手牌、牌型与净盈亏（+ / -）及分页回放。
   - **实时排名 (🏆)**：展示桌面玩家与旁观者的累计带入、实时盈亏、全部流水、本局手数、平均底池与对局时长。

8. **真实声效合成**
   - 内置 Web Audio API 合成发牌刷牌声、筹码碰撞声、敲桌过牌声、全下警报声与获胜欢呼音效，免外部音频资源依赖。

---

## 🚀 快速启动

```bash
# 1. 进入目录
cd game-hold-me

# 2. 安装依赖 (已安装则跳过)
npm install

# 3. 启动开发服务器
npm run dev

# 4. 生产打包
npm run build
```
